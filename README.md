# Pink Jamu × Café Partnerships Website

A responsive Next.js website based on the 2026 Pink Jamu café partnership deck and aligned to the supplied Pink Jamu brand guide.

## Run locally

Requirements: Node.js 18.17+ and npm.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy to Vercel

1. Create a Git repository and push this project.
2. Import the repository at https://vercel.com/new.
3. Keep the framework preset as **Next.js** and the build command as `next build` (default).
4. Deploy. No environment variables are required.

You can also use the Vercel CLI from this folder: `npx vercel`.

## Notes

- The site uses the brand's hot pink, cream, green, yellow and black palette, rounded display typography, playful starburst graphics, botanical/product imagery, and friendly copy.
- Contact details and product availability follow the supplied partnership deck. Beras Kencur is shown as coming soon.
- Product imagery is extracted from the supplied PDF deck; replace these with original high-resolution product photographs before a production launch for the best quality.
